## Status

Production coordinator CPU validation only. No runtime, headset or performance
claim follows from these fixtures. The live candidate remains default OFF.

`build.cmd` compiles the actual coordinator, color, interop and output sources
with `/W4 /WX /O2`, then runs `coordinator_cpu_test.exe --self-test`. The fixtures
exercise actual frame admission/recovery and NGX camera construction. A caller
with the normal NO_ZOOM wire size is placed against a PAGE_NOACCESS guard to
detect optional-tail overreads. Distinct source texture identities bind the
anatomical eye independently from the SR slot index. Camera cases include
asymmetric frusta, nonzero translation, current/previous depth encodings,
projection into the previous image, actual jitter/MV units and unsafe refusals.

GPU/NGX/HUD entry points and shader compilation are aborting link-time tripwires.
The test checks that D3D11/D3D12/DXGI/shader-compiler modules remain unloaded.
This verifies CPU behavior only; tripwires do not stand in for live GPU work.

`compile.cmd` compiles the coordinator and three actual live hook translation
units. It accepts an optional generated-header directory; by default it uses
this worktree's `build\gen`. The full sanctioned native Windows build remains
required to validate the complete candidate and generate its own shader headers.
